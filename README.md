## 🐙 GitHub Flavored Markdown (GFM) Cheat Sheet
### 🚨 1. GitHub Alerts / Callouts
Use these specific blockquote tags to highlight notes, tips, warnings, or crucial information in READMEs or issue comments.
> [!NOTE]
> Useful information that users should know, even when skimming the page.
> [!TIP]
> Helpful advice for doing things better or more efficiently.
> [!IMPORTANT]
> Crucial information necessary for users to succeed or prevent errors.
> [!WARNING]
> Critical content demanding immediate user attention to prevent failures.
> [!CAUTION]
> Negative consequences of an action or severe security implications.
---
## 👥 2. GitHub Platform Integrations
GitHub automatically turns these shortcodes into active hyperlinks when typed into Issues, Pull Requests, or Commit messages.
* **User Mentions:** Type `@username` to ping and link to a specific GitHub profile.
* **Issue/PR Links:** Type `#42` to link directly to issue or pull request number 42 in this repository.
* **Commit Links:** Paste a commit SHA hash (like `abc1234`) to automatically link to that specific commit.
* **Emojis:** Type shorthand codes like `:sparkles:` ✨, `:octocat:` 🐙, or `:white_check_mark:` ✅ to render icons.
---
## 📋 3. Task Lists & Collapsible Details
### Interactive Checkboxes
GitHub renders these as clickable checkboxes inside tracking lists.
- [x] Completed project setup milestone
- [ ] Remaining issue documentation
- [ ] Open pull request review
### Collapsible Toggle (Accordion Layout)
Great for hiding long logs, system outputs, or lengthy code segments inside issues.

# 📄 Basic Markdown Syntax Reference

- `#` = Header 1
- `##` = Header 2
- `###` = Header 3
- `####` = Header 4
- `#####` = Header 5
- `######` = Header 6
- `**text**` = **Bold**
- `*text*` = *Italic*
- `~~text~~` = ~~Strikethrough~~
- `-` = Bullet point
- `1.` = Numbered list item
- `- [ ]` = Unchecked task box
- `- [x]` = Checked task box
- `` `text` `` = Inline code font
- `> text` = Blockquote quote indent
- `---` = Horizontal separator line
- `[Text](URL)` = Hyperlink
- `![Text](URL)` = Inline image
